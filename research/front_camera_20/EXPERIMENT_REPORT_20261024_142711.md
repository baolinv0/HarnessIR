## 1. 摘要

本实验比较四条本地开源权重编辑链：Qwen、FireRed、FLUX 和 FIBO。输入 A 为 S26 linear 经冻结 baseline 处理后，按统一显示出口生成的 prediction；输入 B 为同场景、未像素对齐的 iPhone 外观参考。A 决定人物身份、表情、物体、文字、几何和构图，B 只提供指定亮度、颜色和影调关系。

实验首先比较 `native / shared / model_aware` 单轮系统，再用全链不接收 B 的 `A-only model_aware` 消融分析参考的价值。可选反馈实验比较相同最大生成次数下的反馈和固定条件重采样。主要评价采用模型身份隐藏的人评，以“技术完成 + 可见目标改善 + 人物/内容保真 + 自然度不下降”为可用性条件；所有计划运行、技术失败和缺失评分分别保留。

**结果摘要**：待运行，不填写模型排名、质量提升百分比、GPU 时延或显著性结论。

## 5. 评价方法与评分完整度

模型身份隐藏；A 为固定源锚点、B 为未对齐外观参考、C 为匿名待评图。试验顺序固定随机化，组织者单独保管真实映射。该设计为 model-masked review，未声称双盲。

| 评价项目 | 规则 | 实际情况 |
|---|---|---|
| 外观改善 | 相对 A 的指定目标，-2/-1/0/+1/+2 | 待填写 |
| 保真 | no_damage/minor/major/uncertain；重大/不确定需盲态复核 | 待填写 |
| 自然度 | 相对 A，-2..+2；伪细节、塑料皮肤等另记 | 待填写 |
| 可用增强 | 技术完成、有效编辑交付、外观改善、自然度不下降、保真通过 | 待填写 |
| 评审 / 显示环境 | 推荐 3 人，同 SDR 显示；只有 1 人则注明 | 待填写 |
| 评分覆盖 | 已评分 trial / 应评分 trial；缺失与理由 | 待填写 |
| 基线控制 | 独立 A 作为 C 应为无变化 | 待填写 |
| 自动 verifier 与人评一致性 | 观察性对照；自动 accepted 不是画质真值 | 待填写 |

三人情况下至少 2/3 认可外观改善及自然度不降；任何 major/uncertain 先做隐藏模型身份的争议复核。保真未解决不能计可用。minor 须确认不影响身份/内容且无需修复。保留原始评分和裁决，`usable` 由预定规则汇总，不能事后重新调阈值。

技术失败但仍留下有效选中图的运行可进入画质诊断，技术主终点仍记失败；没有选中交付图与 source_baseline 回退不能当编辑成功。匿名材料只覆盖输入报告出现的 runs，计划清单中没有任何报告的任务仍须由组织者补入 missing 分母。
