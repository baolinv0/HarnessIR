## 填报规则（执行人员先读）

1. 所有支持结论的数字、关键配置、代表性实际 Prompt、失败及人工看图观察，必须写在本文件内。不要用“见另一个文件/图片/网页/服务器日志”代替必要内容。
2. 不要求回传图片、截图、HTML、JSON、CSV、压缩包、完整日志或仓库链接；不要插入图片、Base64 或图片占位链接。原始图像和日志留服务器保存，路径、哈希仅作可选审计索引。
3. 运行表、指标表和逐图表尽量由工程程序自动填入；人工主要填写看图观察、分歧与结论。只报告已运行阶段，不为了填满模板扩大实验。
4. 未运行写 `NOT_RUN`；执行失败写 `FAILED` 并给原因；未评价或未知数值写 `null` 并给原因；不适用写 `NA`。不得用 0、空字符串或均值填补缺失。
5. 视觉结论注明来源：人工观察 / 自动指标 / VLM 评价。VLM 评价不能冒充人工评价；没有人工看图时，恢复完成度、自然性和可交付率应标为尚未人工确认。
6. 实际 Prompt 原样粘贴，不重新概括、翻译或事后改写；不回传模型的完整思考过程。共享文本只写一次，其他位置引用本文件内的文本 ID。
7. 必须保留失败、低分和反向结果；不能挑最佳 seed，也不能将失败回退到 Raw 的输出记成 PE 成功。
8. 本文件足以支持配置、统计和证据链审查；仅收到文本的一方没有直接看到图片，不能把本报告标成“接收方已独立视觉验证”。
