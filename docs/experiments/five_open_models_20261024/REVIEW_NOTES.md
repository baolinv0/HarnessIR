# 方案审查记录

日期：2026-10-24。审查类型：原代码只读核对＋新上下文的同模型族实验设计评审。`review_independence: same-family`；`acceptance_status: provisional`。

本审查确认的是方案的可解释性与实现边界，不证明真实模型可运行、画质改善、统计功效或研究新颖性。

## 已纳入的关键修正

1. 以原始HarnessIR入口为主，接入executor factory；不因复用v3适配而迁移控制器。
2. 显式区分单次前四阶段与开启Verify/Refine；每轮回原LQ。
3. D/O/A固定同模型原生compiler；D不能获得Harness诊断工具证据。
4. O/A共享冻结原始composition，适配不能扩大重建许可。
5. 默认颜色对齐与尺寸归一化作为显式配置，raw始终保存。
6. F/S共享首图、相同新增seed与selector；主实验两候选，第三候选独立。
7. 主反馈覆盖完整20张，避免只挑某模型失败图；无可支持反馈时不编造refine。
8. BLOCKED与可运行后的生成失败分开；所有失败/回退保留分母。
9. 不确定内容不强转成tie；按源图/scene聚类，跨模型结果不能当独立新图。
10. 报告工程继续门槛与正式证据的区别；20图不能自动证明严格安全非劣。

## 仍需服务器验证

- 五个真实checkpoint、compiler与依赖的兼容性、显存和时延。
- native条件是否语义忠实，O/A差异是否穿过compiler保留。
- 模型是否能在不破坏内容的情况下恢复拖影和低光可见性。
- 人评规则一致性、未知文字真值及最终效应区间。
