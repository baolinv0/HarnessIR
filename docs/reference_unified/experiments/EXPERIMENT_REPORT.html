主表六臂实际任务语义解释边界

  
legacy_native_abreference_enhance；strategy=native；A+B；旧路径；单次。Direct 主对照；不接收 Harness intent。

  
legacy_shared_abreference_enhance；strategy=shared；A+B；旧路径；单次。shared 是编译策略名；study builder 未自动注入同一个 shared_intent。

  
legacy_aware_abreference_enhance；strategy=model_aware；A+B；旧路径；单次。增加模型适配 guidance；本臂与其他臂独立规划。

  
retouch_shared_abreference_retouch_v2；strategy=shared；A+B；单次。统一语义、覆盖与交付合同；系统包级比较。

  
retouch_aware_abreference_retouch_v2；strategy=model_aware；A+B；单次。C1 主方法；与 native 的差异不单独归因于某个模块。

  
legacy_aware_arestoration；strategy=model_aware；仅 A；独立 brief_a/regions_a。输入、区域、brief、缓存、runtime 验证不得泄露 B；共同 B rubric 仅离线使用。辅助上下文对照。

  

  
B2：同 A、双参考
在主表输出前选定 12 个测试 source-group 及 B₂，两个参考应有事前可区分、可实现的方向；冻结各自 A/B 共同评价。两个方法 × 3 repeats。B₁ 端点仅引用 B1 已有 72 个 run；B₂ 端点新增 72 个单次任务。保持同一 A 与相应条件，记录差异、参考方向跟随、A 保护和未知。C2 解释为整体系统 B 干预；提示、规划、编译与生成共同改变，无法分离 primitive 因果贡献。
B3：反馈删除与强预算对照
预选 12 个测试组；3 条件 × 3 repeats × 最多 3 次图像尝试，最多 324 个新槽位：F1=最终 aware+feedback；F2=相同最终 aware+resample；F3=legacy native+resample。F1/F2 只在冻结的反馈策略上不同，才可解释为反馈删除检查。F3 是强预算 Direct 对照。三者均为新任务，policy/task hash 不同；不能假定与 B1 r0 相同或按“同 seed”声称复用相同初始候选。

  
F1/F2/F3 的预算上限、实际消耗、停止原因和选择器同时报告。冻结选择器及其可见信息；不得以离线最终测试评分择优。保留全部候选及每轮动作 revise_prompt/gather_evidence/manual_review/stop，精确绑定候选、round、verification 与前驱。反馈不改冻结目标，编辑每轮仍从 A+B 开始。若实现停止规则导致实际调用数不等，只能称“相同上限”，不能称“实际调用完全相等”。

  
先全图，再全对象/材质，数字最后解释

  
  1. 用真实 A/B/C，方法标签隐藏；先观察全图六轴：tone、color、brightness、lighting_naturalness、material_relationships、processing_appearance。
  2. A 内容保护另列：identity、layout/geometry、texture、OCR/text、naturalness、reference_content_leakage、unsupported_detail；按实际冻结 rubric 字段完整保存。
  3. 随后观察完整人脸、对象与材质单位，禁止恢复脸内局部编辑协议。数值仅解释，有冲突时保留。
  4. 评分者披露独立性、先前暴露、观看设备、尺寸、颜色依据、方法标签是否可见；模型自评不能当独立人工。盲方法标签不保证评审从未见图。
  5. 原生细节必须实际看绑定 A/C 的 native 1:1 或明确 native_zoom；缺失或非独立/低置信保持 uncertain。缩小预览不证明细节保存。
  6. 保存每份原始评分。完整决策字段有分歧时保留 unknown；明确裁决必须引用全部原始 rating hashes，并选取实际意见，不能以导入顺序、平均分或静默多数票覆盖。

  
CLI 能做什么、哪些需要控制器和后处理
