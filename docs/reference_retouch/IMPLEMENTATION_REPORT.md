## 实验驱动的修改

| 已发现的问题 | 工程处理 |
|---|---|
| 普通增强也能满足提亮暖肤，不能据此证明参考利用 | 独立记录参考观察、A/B 差异、证据、目标覆盖及每项目标结果；保留直接/无参考对照的解释边界。 |
| 自参考仍被编辑器明显改变 | 将闭合的 already-close 诊断接到零编译、零生成的成功路径；证据不足不能伪装已满足。 |
| 全局 accepted 隐藏可选目标残差和交付限制 | 逐目标完整验收，外观、内容/自然度、原生尺寸与细节门槛分开记录。 |
| 低分辨率原生输出被放大后展示 | 检查真实 native PNG 和冻结下限；插值图不用于原生门槛。能力不足而无支持改法时停止重绘。 |
| 提示可能重复方向而遗漏参考事实或改变验收 | delta_id 追溯、源/参考事实分离、冻结合同 artifact、反馈合同相等检查与版本隔离。 |
