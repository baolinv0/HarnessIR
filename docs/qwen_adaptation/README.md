# Qwen-Image 适配：总览与当前状态

记录日期：2026-10-13。核查基线：`main@3c48c206bb15027366dd9326e8e1fa552c6e6542`。

## 1. 目标与边界

在冻结图像 Executor 的前提下，使 HarnessIR 的诊断、Prompt 编译和验证更适合 Qwen，先消除相对 Direct 的负收益，再判断 Agent 是否提供独立收益。

本记录维护未运行图像模型或部署模型。新增 H07 为用户报告的 11 图 P0/P1/P2 实验，尚未取得原始图像和运行日志。仓库基线只注册 NB2/GPT Executor，未见 Qwen 专用注册；用户本地 Qwen 实验与本仓库代码不是同一份已核验运行快照。

## 2. 当前结论

- **最新 H07（USER_REPORTED）**：P2 提亮接近 P0，但 LVLM 转述显示白昼化和塑料感仍在，尚未显示超越 Direct 的质量收益；下一轮同时比较 P3=简单目标+官方 PE 与 P4=相同目标+Harness 诊断+同一 PE。详见 [H07 实验记录](experiments/H07_lowlight_11_P0_P1_P2_20261013.md)。

- **用户实验报告**：Qwen-Image-Edit 的单图对照及 Qwen-Image-2.1 的三图 ROI 数据都显示，旧 Harness Prompt 的输出比 Direct 更暗。
- **主要解释，尚未完成归因**：保守措辞与恢复目标冲突，是强候选原因；Prompt 长度、诊断错误、采样与后处理仍须隔离。
- **已复测的工程资产**：离线 `qwen21-restoration-adapter/0.1` 有 10 类模板，36 项单测通过；不等于图像质量已改善，且尚未接入本仓库。
- **已形成的修改建议**：恢复操作与场景分离；诊断 → 结构化意图 → Qwen 专用编译；避免先写 NB 长 Prompt 再做关键词删改。
