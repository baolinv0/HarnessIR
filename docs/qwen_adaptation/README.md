# Qwen-Image 适配：总览与当前状态

最近维护：2026-10-14。历史源码核查基线：`main@3c48c206bb15027366dd9326e8e1fa552c6e6542`；本次H08-n1文档审查基于 `fce8d3c3a9c7c9b0c68712c933a1217b1a431333`。

## 1. 目标与边界

在冻结图像 Executor 的前提下，使 HarnessIR 的诊断、Prompt 编译和验证更适合 Qwen，先消除相对 Direct 的负收益，再判断 Agent 是否提供独立收益。

本次文档审查未运行图像模型或部署模型。H07为用户报告的11图P0/P1/P2，H08为25图NB2/Qwen对比，H08-n1新增生产端报告的6图×3seed×5臂×2CFG开发实验；样本重叠未知，不相加样本量。已读取汇总和配置报告，原始图像、逐seed分数和运行快照仍未附于当前仓库。历史源码核查基线只注册NB2/GPT；生产端新报告使用本地Qwen专用分支，二者不是同一份已核验运行快照。

## 2. 当前结论

- **最新H08-n1（生产端实测报告；本次报告级审查）**：CFG4下compact/region_target三项NR-IQA开发集均值高于simple；CFG1结果混合。原Compose在两配置下均低于simple；删除所列保守条款未明显恢复。支持推进压缩重写候选，尚不支持纯长度主因或区域独立收益。CFG是本轮受控因素，不能用其差异解释H08固定CFG4下的臂内负收益。见[实测与审查](evidence/cfg_d_ablation_20261014.md)、[配置核查](evidence/qwen21_config_audit_20261014.md)。

- **最新 H08（USER_REPORTED）**：25图中，两种 Executor 的框架臂相对 direct/simple 均降低三项 NR-IQA 均值，Qwen 亮度下降更大；指标不支持 NB2 全面占优。原主张“弱模型是瓶颈、框架没问题”审查为不支持；先核配置、做约束消融和专用/确定性基线，能力上限仍未知。详见 [H08 实验与审查](experiments/H08_lowlight_25_NB2_Qwen_20261014.md)。
- **H07（USER_REPORTED）**：P2 提亮接近 P0，但白昼化和塑料感仍在，未显示超越 Direct 的质量收益；官方PE的P3/P4仍未报告执行。详见 [H07](experiments/H07_lowlight_11_P0_P1_P2_20261013.md)。

- **用户实验报告**：Qwen-Image-Edit 的单图对照及 Qwen-Image-2.1 的三图 ROI 数据都显示，旧 Harness Prompt 的输出比 Direct 更暗。
- **机制仍开放**：早期优先怀疑保守措辞；H08-n1的drop_guards结果使这条解释降权。压缩重写整体有开发证据，但长度、重复、语义组织与目标优先级仍需隔离，不能换成另一项唯一根因。
- **已复测的工程资产**：离线 `qwen21-restoration-adapter/0.1` 有 10 类模板，36 项单测通过；不等于图像质量已改善，且尚未接入本仓库。
- **已形成的修改建议**：恢复操作与场景分离；诊断 → 结构化意图 → Qwen 专用编译；避免先写 NB 长 Prompt 再做关键词删改。
