# 04 · 验证计划与判定边界

返回：[总览](README.md)。以下均为下一轮计划，不是新增实验结果。

## V0 · 先确认比较的是同一执行条件

冻结：真实 Executor 模型 ID/revision、输入字节和最终送入图、预处理、输出尺寸、采样步数、引导参数、negative prompt、随机源、服务端自动改写、后处理、执行次数。配对同一 seed 只用于同一 Executor；不声称不同模型的同名 seed 有可比随机轨迹。

冻结已有 diagnosis/tool_evidence/原 Compose 文本，不在每个 Prompt 组重新诊断。关闭 redo 和 best-of-N。固定原任务标签与独立评估规则；所有组写不同输出目录，不能被 resume 当旧结果跳过。

具名 lowlight 的 copy 与 pure mix 的 AdaIN 要分别核对。保存 raw-model、几何处理后、颜色处理后图像；报告测量基于哪一级。

## V1 · 机制消融：不用含义漂移的 A/B/C/D

| 新 ID | 唯一改变 | 回答的问题 |
|---|---|---|
| P_DIRECT | manifest 原始短请求 | Executor 简单指令基线 |
| P_ORIGINAL | 冻结完整 Compose Prompt | 复现旧负收益 |
| P_DROP_GUARDS | 仅移除／中和与恢复目标冲突的自动条款 | 保守导向的贡献 |
| P_COMPACT | 保留原目标和约束，压缩重复表达 | 长度和重复的贡献 |
| P_TARGET_FIRST | 保持其他部分，改成目标优先的正向表达 | 指令目标／优先级的贡献 |
| P_TEMPLATE_01 | 同一已确认意图，经 v0.1 编译 | 多项工程改写的整体收益，不能单独用于根因归因 |

编辑 P_DROP_GUARDS 时保存逐句 diff；不得删除用户真实硬限制。删句会同时缩短长度，因此它不是完美因果隔离；结合 P_COMPACT、语义审核及必要的等长度近似改写，报告残余混杂。不能用“越长越差”替代实验。

先用已有三图做回归检查；正式比较使用新样本。建议起始 20–30 张分层夜景、每图至少 3 个配对 seed，最终样本量按方差和目标效应重新估计。这是实验预算建议，不是统计充分性的保证。

## V2 · 多退化适配

分别报告低光、去噪、去模糊、去雾、压缩及混合退化；其余操作按资源单独验证。必须包括夜景纯去噪、白天主体欠曝、有意 bokeh、彩色照明、地面积雪、高光饱和等负例。

混合退化不准省略 manifest 明确要求的任务。超过 v0.1 三项预算应中止并要求明确优先级或使用另一个已验证方案，不静默截断。

## V3 · 区分 Prompt 收益与 Agent 收益

先固定意图来源比较 Direct/原 Compose/模板；再固定模板比较人工或 manifest 意图与 Harness 诊断意图。人工意图作为诊断参照，不能把其结果直接算成全自动 Agent 性能。

可选单独比较原图+真实目标→官方 PE，与 Harness 证据+PE；记录额外 VLM 成本。单次路径确认后再开放 redo，并与同图同次数 Direct 多 seed 的候选预算对齐，分开报告候选产生、选择和最终交付质量。

## 评价与门槛

程序测试：schema、未知任务、属性冲突、bypass、真实执行字段、错误记录、尺寸、逐轮适配、NB 默认回归。

图像评价：每项任务的去退化效果、结构／身份／文字保真、色彩和曝光漂移；有合适 GT 时增加全参考指标，无 GT 时结合盲评与独立 D/F 评分。评价标准来自冻结的真实任务，不来自被比较的 Prompt。

ROI 统计必须声明坐标、mask、resize、亮度公式、色彩空间、数据范围。road_std 或梯度增大也可能来自噪声和伪纹理，不能证明细节恢复；平均亮度不是物理曝光量。

预先选定主要指标和可接受保真退化范围；不得看完测试结果再定门槛。报告逐图配对差异、置信区间、失败率和成本；bootstrap 以图像为采样单位，seed 是图像内重复，不能伪增样本数。

若模板只能恢复到 Direct 而不能超过它，结论是“消除迁移负作用”，不是“Agent 增益”。若不如 Direct，保留失败并停止增加无证据复杂度。
