## 两项关键澄清

**I-05 不是已经发现历史实验被颜色对齐污染。** 当前源码中 pure `mix` 使用 AdaIN，具名 `lowlight` 使用 copy；历史运行究竟走哪条路径仍需日志。raw-model、几何处理后、颜色处理后输出应分开保存。

**I-09 不是 Qwen 只能接收单段文本的证明。** 官方 PE System Prompt 规定其改写结果为单段；v0.1 的多段输出尚未经对比，记录为格式差异和待验证项，而非直接认定运行错误。
