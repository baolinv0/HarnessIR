# 03 · Prompt 适配决策与模板设计

返回：[总览](README.md)。本章是设计建议；已实现部分仅指独立 v0.1 资产，不代表仓库已经接入。

## 决策 D-01：不是“激进”对“保守”，而是编辑属性明确

NB 与 Qwen 的官方指导都强调编辑目标及保持内容；没有依据将二者概括成“NB 喜欢长、Qwen 只能短”。Qwen 官方编辑改写更明确地区分目标属性、非目标属性和图像依据。[O1,O3，见证据索引]

本项目规则：先说明需要改变的属性与可观察目标，再用一份保持条款约束内容。目标是恢复，不是“尽可能提亮”。用户明确要求不改变曝光时，不得擅自删除该要求。

## 决策 D-02：操作模板为主，场景为辅

| 操作名 | 需要改变的目标 | 不应自动改变 |
|---|---|---|
| low_light | 欠曝区域和中间调可见性 | 对象、几何、真实夜景语义 |
| denoise | 不期望的亮度／色噪声 | 曝光、白平衡、有意颗粒 |
| deblur | 非预期运动／失焦模糊 | 有意背景虚化、身份和文字 |
| dehaze | 遮挡性雾幕及局部可见性 | 天气替换、天空重绘 |
| derain | 遮挡内容的雨丝 | 湿地反射；其他退化需单独指定 |
| desnow | 遮挡内容的飘落雪花 | 地面、屋顶等积雪 |
| deblock | 压缩块、振铃、蚊噪 | 真实边缘与纹理 |
| super_resolution | 指定输出尺寸下的有依据细节 | 构图；真实尺寸由执行器控制 |
| color_cast | 不期望的偏色 | 有意义的彩色照明 |
| highlight_recovery | 仍有信号高光的亮度与层次 | 对完全饱和区域虚构细节 |

模板原文快照：[templates_v0.1.json](prompts/templates_v0.1.json)。它们是实验设计，不是官方校准恢复模板。

夜景曝光正常且有噪声 → `denoise + night`；白天逆光主体欠曝 → `low_light + day`。退化严重程度与用户接受的编辑强度分别记录。

## 决策 D-03：结构化意图是稳定接口

```json
{
  "scene": "night",
  "edits": [
    {"task": "low_light", "strength": "strong", "regions": ["underexposed road", "building facades"]},
    {"task": "denoise", "strength": "mild", "regions": ["noisy shadow regions"]}
  ],
  "locks": []
}
```

区域只是示例，必须来自原图或已核验诊断。v0.1 只接受 scene/edits/locks，不能直接把额外来源字段塞入该对象。证据来源、置信度、原始请求放宿主记录；未来扩展 schema 时另加版本。

v0.1 强度为 mild/moderate/strong，最多 3 个不同操作；这是起始设计预算，不是 Qwen 能力上限。顺序表示优先级，不代表执行多轮。`edits=[]` 表示确认无需编辑，而不是无法判断任务。

## 决策 D-04：两条入口，共用一套编译

主路径：`原图/用户目标 → 现有诊断 → 已确认意图 → 确定性模板编译 → Qwen`。

兼容路径：`原始用户目标 + 原图/诊断 + 旧 Compose Prompt → 宿主语义提取器 → 严格校验意图 → 同一编译器`。

只有旧文本时不根据关键词猜任务。`do not denoise` 不是去噪请求；用户硬限制与 Composer 自动措辞要区分权限来源。显式 intent 模式是重新表达目标，不是逐句忠实翻译旧 Prompt。

## 决策 D-05：最小保持与冲突检查

组合时统一汇总允许改变的属性，然后只生成一份保持约束；不能拼接完整“提亮”和“曝光不变”模板。低光与曝光锁冲突应报错。阴影提升与高光压低并存时必须明确区域；不同文字标签并不能证明掩码互不重叠。

v0.1 只有全局属性锁；局部区域外保真仍需输出端检查。强度词不等于 EV、百分比或去噪 sigma。完整 [低光 v1 原稿](prompts/lowlight_v1.txt) 独立保留，不在历史记录中悄悄替换。

## 决策 D-06：官方改写器仅作为可选独立基线

官方 PE 的原始回答字段是 `rewritten_prompt/wh_ratio/ratio_follow`；其工具输出记录提供 `positive_prompt`、`parse_ok` 等，须区分层次。[O2]

只在解析成功后把真正的编辑文本送给图像 Executor；尺寸另传。避免默认在模板后再改写，从而同时改变两个变量。PE、当前 Diagnoser、图像 Executor 是三个独立组件；不能混写模型 ID 和算力预算。它不是本次已部署组件。
