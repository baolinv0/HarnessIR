## 使用

- 打开 `index.html` 查看这 80 张；Data 根目录 `index.html` 可进入基础与新增浏览。
- Data 根目录 `manifest.json/csv/jsonl` 已合并成 164 条。此目录同名文件只有新增 80 条，**其中图像路径也相对于 Data 根目录**。

- `roi_manifest.json` 是原图像素坐标的粗语义 ROI，`xyxy` 右/下边界不含。评分前需人工细化；不是人脸关键点真值，不是可辨文字答案。

- 用 Data 根目录 `scripts/validate_dataset.py` 可重新检查实际路径、完整解码、哈希、尺寸及人物 Mask。搬迁目录后先重导出官方输入清单。

## 数据证据边界

**RAIM 2026**：原输入是实际弱闪光拍摄。参考由专业设计师修饰，目标是强闪光审美效果，不是独立物理测量出的自然肤色/皮肤真值。它支持风格目标评估；不能用更接近修饰 GT 来证明身份、年龄感或皮肤保真。人物 Mask 也不是面部身份 Mask。通用保真任务与强闪光风格任务分开报告。

**WildDark-Face**：作者说明是网络真实低光人脸，发布文件已经对齐/裁剪为 256×256。没有逐图原摄影者、URL、拍摄事件 ID、相机或照片许可。已用原作者链接 ZIP，核对成员 CRC 并保留字节；这不等于能证明每张相互独立或未经摄影后期。22 张按可见脸部画面/照明/构图筛选，明显相近画面排除；独立拍摄事件仍待核查，不能把这 22 张作为 22 个已证明独立的统计单位。不能证明闭源执行器从未见过这些网络图。

**ReWiTe**：OPPO Find X6 真实长焦 `tele`，不取人工 bicubic `wide_2x/4x`。原任务的 GT 与 wide 相机共享光路，不能直接断言与本次单张 tele 像素对齐。因此本次不下载/伪配这些 GT。当前样本主要是密集结构、文字与纹理压力测试，多为日间；不能代替夜间手持长焦低 SNR 专项。发布 PNG 可能有作者配准/裁剪，不能保证原相机直出。

**COZ**：保留作者发布的真实光学跨焦段 LR/HR。低细节由实际焦段变化形成，整理没有给 HR 人为下采样。但作者已配准/裁剪，输入的较低焦段不能冒称手机高倍率长焦相机原帧。按 RealZoom 跨焦段细节恢复轨道报告；像素尺度及配准必须先核实，当前 `pixel_metrics_ready=false`，不能把未核验的 PSNR 当成性能结论。

**Commons**：人物运动模糊来自真实曝光，不是数字加模糊。其中 Rick Doble 是有意采用长曝光的实验摄影，是“不可恢复信息/拍摄意图”的边界测试；不要把所有艺术性模糊都强行清除。另一图为舞者。烛光人像保留烟雾和暖色照明。原上传照片可能已经经过摄影后期，EXIF/来源说明和许可证据均保存。
