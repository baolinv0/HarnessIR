# HarnessIR 五阶段完整实验与报告

2026-10-24 · 版本 1.0 · 目标分支 `feat/stage-model-lab-20261022`

**项目目标：让语义差异诊断 D、动作规划 P、原生条件编译 C、图像执行 E、结果判别 J 可以独立测试、横向比较、复用上游，并定位哪一环限制了参考增强效果。** 在此基础上验证模型专属规划是否比每个编辑器自己的原生路径更有效。

这不是仅选择 27B/32B/8B 的温度，也不是仅比较最终图片。本分支是实验台，还没有实现完整的自动能力学习、策略路由或自动多轮优化。

## 执行顺序

1. 读 [目标与现有方案审查](GOALS_AND_REVIEW.md)，明确要证明什么、哪些功能当前没有。
2. 按 [完整实验计划](EXPERIMENT_PLAN.md) 执行 F0、D/P、四模型 C/E、J 与归因。
3. 用 [服务器运行说明](SERVER_RUNBOOK.md) 配置命令、绑定正确的 C→E，并生成报告。
4. 复制 [完整报告模板](REPORT_TEMPLATE.md) 为实际 REPORT.md；填 [执行清单](EXPERIMENT_TRACKER.md) 和 CSV。

核心生成量：4 case × 4 editor × N/G/M 三臂 × 2 seed = 96 张；人工固定意图 I 的独立 C/E = 32 张；B 参考替换检查新增 8 张。合计 **136 张**，**64 份冻结编译条件**。可按步骤回传，未完成部分明确标注，不把接口通过等同于效果通过。

原 [VLM 校准计划](../vlm_stage_calibration_20261024/README.md) 保留为前置专题；已有可用配置及可追溯结果可复用，不要求重复全部 100 次。该旧计划不能单独作为完整项目验收。

本包为完整计划、源码审查与待填报告，未新增服务器实验结果；不据此声明四个原生模型已在目标服务器跑通。
