## 3. LVLM 评估（用户转述，未独立复核）

- P0/P2 视觉接近，天空灰/棕，出现白昼化；P2 未显出更好的夜感保持。
- P1 在多张图比输入更暗或持平，用户列出 Rows 1/3/5/7/9；没有行号与样本 ID 对照，不补造具体文件名。
- Author 夜感、高光、对比度更好；用户转述的综合排序为 Author > P0 ≈ P2 > LQ > P1。
- P0/P2 在自行车轮、狗毛、水面反射上有过度平滑/塑料感；P1 噪声放大。上述观察需要原图、盲评协议与日志确认。

## 4. 结论与修正

| 判断 | 当前支持程度 |
|---|---|
| P2 提高汇总亮度，恢复到接近 P0 的量级 | 支持，限于用户报告的 11 图汇总 |
| P2 优于 P0 的恢复质量 | 未显示；转述的视觉结果接近 |
| P2 和 P0 统计等效 | 未证明；缺逐图/重复数据与等效性界限 |
| 保夜措辞太弱是唯一失败原因 | 未证明；需隔离措辞、编辑强度、诊断和执行器因素 |
| 官方 PE 能解决白昼化与塑料感 | 待检验 |
| Harness 诊断有独立质量增益 | 待 P4 对 P3 检验 |

更新后的工作结论：**P2 消除了 P1 所表现出的提亮不足，但没有建立超过 Direct 的质量收益；夜感与材质真实性仍是失败项。** 这支持从整体提亮目标转向局部可见性与区域照明关系的检验，而非简单加强全部保留条款。

`sh_std` 是亮度分布统计量，增加也可能来自曝光、对比度、噪声或伪纹理，不能直接认定细节恢复。Author 是不同 Executor 的系统参考，不能作严格性能上界、真实 GT，或 Prompt 单因素因果证据；不把 Author 图像输入下一轮请求。

同模型新上下文审查：`claim_supported=partial`、`review_independence=same-family`、`acceptance_status=provisional`。数值比较可信度较高，转述视觉判断中低，机制归因与泛化低；原始实验完整性审计未执行。

保留 P0/P2 对照与 P1 失败记录。P3/P4 的任务目标、允许操作、全局保持要求一致；P4 只增加图像证据，不偷偷增加任务或更改目标亮度。诊断冻结一次，不在各组重新运行。两组使用同一 PE checkpoint、system prompt、参数和 Qwen Executor；如果 P4 还增加其他工具，成本与证据来源另列。

PE 是通用编辑改写器，不是经过证明的图像恢复控制器。其官方规则同样强调目标属性显著改变；因此它可能继承过强提亮要求。输入应来自已确认的原始目标，不直接扩写 P1 的冲突长 Prompt 或无条件复用 P2 的强提亮措辞。

诊断记录建议分开：
1. **可见事实**：哪些区域欠曝、哪些是自然暗区、光源与材质位置；未知内容保留未知。
2. **期望变化**：具体目标区域的可见性改善；不要把所有暗像素都当作退化。
3. **保持要求**：非目标区域、原有光照关系、结构与材质；场景性彩色照明不自动纠成白光。

天空是否应保持深暗取决于原图中的真实照明，不能一律设为黑/蓝；月光、暮光、城市光污染不能被硬模板抹掉。狗毛、轮辐、水面反射等对象只在图像证据确认存在时写入，不对 11 张图批量虚构区域。文本区域描述不是掩码，也不能保证像素局部性。

## 6. 执行与评估约定

- 先用现有 11 张开发样本作配对回归，建议每图至少 3 个可记录的 Executor seed；只有旧日志可核验时才直接复用旧输出，否则统一重跑 P0/P2。11 张用于迭代后，再用未参与改写的新图验证泛化。
- PE 优先使用官方离线批处理，缓存每图/每臂改写结果及哈希，再重复 Executor seed，避免把改写随机性混入编辑波动；PE 跨种子稳定性后续另测。
- 每臂一次图像执行，暂不开 redo 或 best-of-N。预处理、尺寸、服务端自动改写与后处理一致，raw-model 和后处理图分开保存。
- 记录 PE 原始请求/回答、`positive_prompt`、`parse_ok`、`wh_ratio`/`ratio_follow`、所有模型 revision 和随机参数。渲染只传 `positive_prompt`；`parse_ok=false` 时标记失败，不能把原始分析回答当编辑指令，也不能静默回退混入成功组。恢复任务按协议保持输入比例，PE 请求新画布时记协议失败，不悄悄改变尺寸。
- 评价以随机化、隐藏 arm 名称的逐图配对盲评为主，分别判断目标区域可见性、夜景照明关系、高光、材质保真与新增内容。LVLM 与人工评价分别记录；用于 Composer 的描述不能作为评分标准。
- 天空/主体/光源分别测亮度分布、分位数及照明对比；这类统计只是解释性指标。高光裁切率不证明被裁切细节可恢复，梯度/纹理能量不替代保真。
- 有经过确认的匹配 GT 才使用全参考指标；Author 输出保持系统参考身份，不改作 GT。
- 在执行前冻结主要评价指标、失败类别和可接受退化范围；报告图像级配对差异与失败率。多 seed 是图内重复，不能当作更多独立图像。

**决策**：P3 改善而 P4 没有增益，采用 PE 简单路径；P4 在独立样本上改善质量且不恶化保真，才支持 Harness 诊断的附加价值。若两者均白昼化/过平滑，继续隔离区域目标和去噪强度；不能据此认定 Qwen 能力极限，也不直接增加闭环复杂度。
