## 区域关系与整幅一致性
- **脸—头发**：B 的 L* 中位差 22.84，大于 A 的 11.56；目标是脸更清楚地从深发中分离，不是将头发同幅度提亮。
- **脸—颈**：两图均脸略亮，差值 1.25 / 2.20；维持细微差别即可，不应制造强烈双色分区。
- **脸—柜体**：两图柜体均略亮于脸，脸减柜体为 −4.50 / −2.65；可使人物与背景更接近，但不可据此强制所有肤色像素都暗于黄色面板。
- **柜体—顶板**：柜体仍较暗，但 L* 差由 −28.44 缩至 −21.05；同时黄色对青绿的 b* 差及彩度差明显增大。目标是亮度层次更接近、色彩材料差别更鲜明，而非统一提亮或统一增饱和。
- **灯箱—脸**：线性 Y 差从 0.77586 降到 0.71925，虽然 B 灯箱自身也更亮。应主要改善人物暗部的可读性，保留高亮灯箱身份，不误解为必须压暗灯箱。
- 以上是区域中位数关系，不是邻接边缘对比、曝光增益或逐像素约束。深衣服、深发、暖肤色、鲜明黄柜体、青绿顶板与近白发光件应在整幅同时成立。

## 原因假设、冲突及限制
**观察不等于原因。** A/B 差异可能包含曝光、白平衡、色调曲线、局部照明与拍摄姿态变化，现有证据不能分离这些成因，更不能断言某个处理参数就是原因。

全图 L* 45.11 / 65.17 与 C* 16.37 / 22.31 只能描述混合场景。全图变暖的概括与顶板更绿、衣服低彩、头发彩度近似不变并存；若执行全局统一暖化/加饱和，反而会破坏参考关系。脸部统计含镜片五官、衣服统计含肩带，柜体/顶板/灯箱是粗多边形，不能把混合中位数作为纯材质标定。
